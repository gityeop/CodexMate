# CodexMate 0.0.68

- Shows Claude Code sessions next to Codex threads in Recent, Projects, and Status views, marked with a small Claude badge. Running, waiting-for-input, plan approval, and unread states work the same as for Codex threads, including pinning, keyboard shortcuts, and the Git Graph window.
- Opens a Claude Code session in Claude Desktop when you select it, and falls back to Terminal when Claude Desktop is not installed.
- Shows the remaining Claude 5-hour and weekly limits under Codex weekly usage, in one bar that turns orange or red when a limit runs low.
- Adds an optional setting to send notifications for Claude Code sessions; it is off by default because Claude Desktop already notifies.
- Keeps CodexMate out of the Dock unless the Git Graph window is open, and no longer opens that window on launch or when reopening the app.
