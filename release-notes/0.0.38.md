# CodexMate 0.0.38

- Adds thread list view modes for project grouping, recently used threads, and thread status groups.
- Adds pinned thread support so favorite threads stay available at the top of the menu and notch lists.
- Adds mode-specific settings for project counts, per-project thread limits, and recent/status section limits.
- Keeps menu bar pin and unpin actions live while the expanded menu remains open.
