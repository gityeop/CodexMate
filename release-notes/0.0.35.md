# CodexMate 0.0.35

- Removes recovery paths that hid runtime, project catalog, and remote state read failures behind cached, session-derived, or empty results.
- Surfaces invalid localized strings, stored settings, and app-server thread payloads as direct failures instead of substituting alternate values.
- Tightens release packaging so signing, Sparkle metadata, appcast URLs, and install-name updates fail visibly when required inputs are missing.
