# CodexMate 0.0.37

- Adds desktop notifications for completed, failed, input-needed, and approval-needed Codex threads.
- Opens the matching Codex thread when a notification is clicked, while keeping failures visible in the debug log.
- Shows the project name, thread title, and concise assistant reply preview in completion notifications without redundant status labels.
- Adds a promo mockup launch mode for generating menu bar and notch menu screenshots with stable sample data.
