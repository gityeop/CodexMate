# CodexMate 0.0.58

- Adds a configurable “Next Chat Needing Attention” global shortcut to cycle through main chats waiting for input or approval, or with unread activity. Subagent threads are excluded.
- Automatically focuses the shortcut recorder after clearing a shortcut, with a highlighted border and a visible recording prompt.
- Keeps the recorder focused after deleting a shortcut with the keyboard so a replacement can be entered immediately.
