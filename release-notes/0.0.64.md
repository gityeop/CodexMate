# CodexMate 0.0.64

- Adds a dedicated Mac window for browsing project worktrees, branches, commit history, uncommitted files, and linked Codex chats.
- Adds fuzzy project search and keeps the worktree sidebar in a consistent position, including for projects that do not use Git.
- Refines shared controls, compact settings dropdowns, and conversation cards.
- Fixes a crash when switching projects and keeps ordinary folders accessible without reporting a Git repository error.
- Refreshes the squashed-slime app icon and its native macOS packaging.
- Keeps menu bar and notch access available alongside the main window. Open Git Graph from the Dock or with Command-1 while CodexMate is active.
